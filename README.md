# [adityaraut.com](https://adityaraut.com)

A personal portfolio website showcasing my work as a Generative AI & ML Systems Engineer.

→ Check out the live site: [adityaraut.com](https://adityaraut.com)

## Overview

### Stack

- Next.js 16 (App Router)
- React 19
- Tailwind CSS v4
- Base UI
- Framer Motion

### Features

- Light & dark theme interface
- Mobile-first responsive design
- vCard integration
- Installable as PWA
- [Haptic feedback](https://haptics.lochie.me/) support
- [Sound effects](https://audio.raphaelsalaja.com/) on interactions
- SEO optimized ([JSON-LD](https://json-ld.org/), sitemap, robots)
- AI-ready with [LLMs.txt](https://llmstxt.org/)
- Analytics with [Microsoft Clarity](https://clarity.microsoft.com/projects)

### Content

Portfolio sections powered by MDX and server components:

- Project showcases with live previews
- Experience timeline with company links
- Blog posts with syntax highlighting
- Dynamic OG images for rich link previews
